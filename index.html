Aperçu

Player — collez votre flux

Collez l'URL d'un flux HLS (.m3u8) ou utilisez les identifiants Xtream pour construire le lien. (Utilisez uniquement des flux autorisés.)

Le player construit un lien compatible HLS si disponible. Certains fournisseurs nécessitent une URL d'API différente ; vérifie auprès d'eux.

Si le flux ne démarre pas, il est probable que le serveur bloque les requêtes cross‑origin (CORS) — contacte ton fournisseur ou utilise un proxy autorisé.
