# Public cible

## Utilisateurs finaux

- **L'utilisateur personnel** — possède un abonnement légal à un fournisseur de
  flux et veut un lecteur agréable sur tous ses écrans. Il ne veut pas configurer
  quoi que ce soit : il colle une URL ou saisit ses identifiants, et ça marche.
- **Le foyer** — plusieurs profils sur le même appareil, chacun avec ses favoris
  et son thème.

## Développeurs

- **Le contributeur occasionnel** — corrige un bug, améliore un style. Il doit
  pouvoir lancer le projet en moins de 5 minutes (voir [Setup](../developpement/setup.md)).
- **Le mainteneur** — comprend l'architecture modulaire, ajoute un moteur de
  fournisseur ou une plateforme (voir [Modules](../architecture/modules.md)).

## Ce que la documentation garantit à chaque profil

| Profil | Ce qu'il trouve ici |
| --- | --- |
| Utilisateur curieux | Objectifs, fonctionnalités, plateformes supportées |
| Contributeur | Setup, conventions, tests, procédure de Pull Request |
| Mainteneur | Architecture, modules, choix technologiques, déploiement |
